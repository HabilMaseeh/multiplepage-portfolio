# Multiple Page Portfolio

A modern, responsive portfolio website built with Next.js, featuring a blog system, projects showcase, and about page.

## Getting Started

1. Clone Repository
```
git clone https://github.com/HabilMaseeh/multiplepage-portfolio.git
```
2. Install Dependencies
```
npm i
```
3. Run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```
